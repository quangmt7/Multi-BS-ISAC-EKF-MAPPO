Integrated Sensing and Communication (ISAC) cho phép hệ thống sử dụng
chung tài nguyên truyền thông và sensing, trong đó resource allocation là một
trong những bài toán quan trọng do sự tồn tại của trade-off giữa hiệu năng com
munication và sensing.

Lưu ý về cách code hàm
- Nên hướng tới sử dụng các class để tạo các instances chỉ lo một chức năng 
nhất định thay vì để nhiều hàm riêng lẻ nhau
- Với mỗi hàm/class cần có chú thích ở dưới bằng cặp dấu """ và bằng tiếng Anh:
    + Argument : các tham số, mô tả dạng (<tên tham số>) (<kiểu dữ liệu>)[kích thước nếu có] : <ý nghĩa>
    + Return : giá trị trả về, mô tả như argument
    + Note (nếu cần lưu ý gì thì thêm vô, không bắt buộc)
